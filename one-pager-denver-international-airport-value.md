# Denver International Airport — Value One-Pager (Quantified)

> **The business case for spatial intelligence.** Turning DEN's Wi-Fi network into a real-time spatial-intelligence platform (Cisco Spaces + Splunk) creates measurable value across **concession revenue, marketing yield, operational efficiency, and IT consolidation** — while supporting **Vision 100** (growing from ~82M toward 100M passengers in an airport built for 50M). Figures below are an **illustrative, parameterized model built on public DEN data + industry benchmarks** — replace each input with DEN actuals to finalize.

**Customer:** Denver International Airport (DEN)  ·  **Program:** Spatial intelligence → AI-Ready Airport  ·  **Platforms:** Cisco Spaces + Splunk (on Cisco wireless, → SDA)
